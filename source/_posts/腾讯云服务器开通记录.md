1 修改新服务器的主机名和服务器字符编码
```
hostnamectl set-hostname  store-es3
localectl set-locale LANG=zh_CN.utf8
```

```

tmpfs          tmpfs      32G  848K   32G    1% /run
tmpfs          tmpfs      32G     0   32G    0% /sys/fs/cgroup
```
4 格式化磁盘 
```
mkfs.xfs /dev/vdb
```

5 查看磁盘的UUID
```
[hdfs@hadoop101 data]$ blkid
/dev/sr0: UUID="2020-06-29-10-08-42-00" LABEL="config-2" TYPE="iso9660"
/dev/vda1: UUID="aaaaa030-aa71-4b3a-8610-3b942dd447fa" TYPE="ext4"
/dev/vdb: UUID="5bbb2b71-956c-41b6-8c48-5e070873cf8a" TYPE="xfs"
```

6 挂载磁盘
编辑/etc/fstab文件，加入如下内容,也就是将/dev/vdb磁盘挂载到/data目录

```
UUID=5bbb2b71-956c-41b6-8c48-5e070873cf8a /data xfs defaults 0 1
```

7 使磁盘挂载生效
```
mount -a
```
